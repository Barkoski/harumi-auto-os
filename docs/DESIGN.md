# Direção visual

Painel dos anos 1990, leitura à distância e pouco movimento. Fundo #2C384B, superfície #35445A, texto #F0F1F6, navegação #ADCBD4, música #C9BEDC e câmeras #B6D0C3. Fontes locais Segoe UI/Roboto/Arial.

Identificação/relógio acima; saudação/personagem à esquerda; atalhos à direita; ajustes abaixo. Sem dados fictícios de carro, clima ou combustível. Personagem CSS estática e provisória. Recuperação nativa fora da UI web. Layout compacto e fallbacks para WebView 83 testados.
