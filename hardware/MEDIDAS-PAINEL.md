# Medidas para encaixar a multimídia no Impreza

Preencha e me mande (ou mande foto de cada medida com a trena aparecendo). Com isso eu ajusto o suporte, a moldura e a
caixa da central antes de imprimir. Tudo em milímetros.

## 1. Teste com o gabarito (o mais importante)

Imprima `caixa-harumi/GABARITOS-1x1.pdf` em **tamanho real / 100 %** (sem "ajustar à página") e confira a régua de
100 mm com a trena. Recorte as páginas 1 e 2 (as duas metades do contorno da tela de 13,3", 323 × 201), junte pela linha do meio e cole num papelão.

1. Apoie o papelão no tampo do painel, no meio, entre as saídas de ar centrais e o para-brisa, com a borda de baixo
   uns 14 mm acima do tampo e inclinado uns 20° para trás.
2. Sente na posição normal de dirigir.

| Pergunta | Resposta |
|---|---|
| O papelão entra na sua linha de visão pelo para-brisa? (sim / não / só a borda de cima) | |
| Quantos mm dá para subir ou precisa descer até ficar bom? | |
| Cobre a saída do desembaçador junto do para-brisa? | |
| Dá para alcançar a tela com a mão sem esticar o corpo? | |
| Atrapalha o retrovisor interno ou a visão do retrovisor direito? | |
| Foto do banco do motorista com o papelão no lugar | (anexar) |

## 2. Tampo do painel (onde vai o suporte)

| Medida | Valor |
|---|---|
| Largura da parte mais plana do tampo, no meio | |
| Profundidade dessa parte (da beira das saídas de ar até a saída do desembaçador) | |
| Inclinação: diferença de altura entre a frente e o fundo dessa parte | |
| O tampo é curvo? (folga embaixo de uma régua de 15 cm encostada de lado a lado) | |
| Por baixo do tampo há espaço para os parafusos de 4,2 mm entrarem (não bate em ferro nem em duto de ar)? | |
| Por onde dá para descer os cabos HDMI e USB: fresta junto do para-brisa, atrás das saídas de ar, outro? | |

## 3. Embaixo do painel do passageiro (onde vai a caixa da central)

Use a página 4 do gabarito (205 × 195 mm, 233 com as orelhas) e uma caixa de sapato de ~73 mm de altura.

| Medida | Valor |
|---|---|
| Largura livre embaixo do porta-luvas | |
| Profundidade livre (de frente para trás) | |
| Altura livre (do tapete ou da parede corta-fogo até o painel). A central pede **~141 mm**: caixa 73 + ventoinha 25 + capuz da saída 43 | |
| Foto de perto da saída de ar do passageiro (formato e tamanho, para encaixar a mangueira de 50 mm) | (anexar) |
| Tem onde parafusar as orelhas M4 (chapa, suporte, plástico firme)? | |
| A caixa fica longe do pé do passageiro e do duto do ar quente? | |

## 4. Tela Hosyond (quando chegar)

| Medida | Valor |
|---|---|
| Largura × altura × espessura da tela (sem capa) | |
| Largura × altura da área que acende | |
| Veio com capa/caixa própria? Medida da capa | |
| Onde saem os conectores HDMI e USB e qual o tipo do USB (micro-USB / USB-C) | |
| Tamanho da placa controladora atrás (largura × altura × espessura) | |
